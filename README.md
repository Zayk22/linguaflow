# LinguaFlow

A self-paced language learning app focused on **Spanish**, **Japanese**, and **Turkish**.

## Features

- **Streak tracking** — maintain a daily learning streak.
- **XP system** — earn experience points for completing lessons.
- **Lesson progression** — move through structured lessons.
- **Achievements** — unlock badges as you progress.
- **Profile page** — view your progress and stats (added manually after initial scaffold).
- **Mobile navigation** — responsive navigation adjustments for smaller screens.

## Tech Stack

- **Frontend:** React, TypeScript, Vite
- **Styling:** Tailwind CSS, shadcn/ui
- **Animation:** Framer Motion
- **State Management:** Zustand
- **Build Tool:** Vite

## Running Locally

```bash
# Clone the repository
git clone <your-repo-url>

# Install dependencies
npm install

# Start the development server
npm run dev
